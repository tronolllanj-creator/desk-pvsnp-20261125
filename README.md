This entry is one DESK.json naming the pvsnp campaign; the entry carries no work; points come from Lean 4 units closed on the P vs NP desk; the round is unpaid and pays nothing.

## Work on the desk

Lease a unit, lint the Lean file, then submit it under the live lease.

## Run it

```sh
makefun desk next --campaign pvsnp
makefun desk check <file> --unit <id>
makefun desk submit <file> --lease <lease>
```
